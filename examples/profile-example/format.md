# Tagged-prose format

Write one paragraph of plain visual prose on a single line. Open with the exact trigger and its class noun
("NORA7, a woman, ..."). Describe only what the supplied target shows: framing, visible pose, expression and
gaze, clothing and removable accessories, hair presentation, surroundings, lighting, and visible image
treatment. No field names, shot tags, timestamps, lists or Markdown. Do not quote readable text.
