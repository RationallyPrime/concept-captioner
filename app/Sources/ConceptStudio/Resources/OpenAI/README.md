# ChatGPT sign-in mark

The white ChatGPT mark comes from OpenAI's approved sign-in assets:
https://developers.openai.com/assets/siwc/sign-in-buttons/chatgpt-logo-white.svg

Retrieved 2026-10-10 and rendered unchanged at 84 × 84 with macOS ImageIO (`sips`) for
the native 21-point sign-in button. Source guidance:
https://developers.openai.com/siwc/ui-ux-guidelines

The mark identifies the OpenAI sign-in action; it does not brand ConceptStudio.
