ConceptStudio offline demo, updated 2026-10-11.

These three photographs depict the same fictional adult. They were generated with OpenAI's
image-generation tool for this application's instructional walkthrough. No real person's
identity or personal photos were supplied. garden.png was generated first; studio.png and
window.png were generated using garden.png as a visual reference. They are synthetic training
examples, not output from a LoRA trained by ConceptStudio and not a dataset-quality experiment.

The app uses prepared per-image captions, prepared dataset advice and simulated service
outcomes. No captioning model, dataset upload, GPU rental or training run occurs in demo mode.
