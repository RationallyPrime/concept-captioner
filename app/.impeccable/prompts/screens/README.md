# Comp prompts: the other eight screens and the app icon

These continue the Instant Print direction set by the approved Review comp (`../../mocks/review-approved.png`).

## Screens

Render each with **review-approved.png attached as the reference image**, so the frame, palette, type and print style match it.
- **Size:** 1536 × 1024.
- **Output:** save each as `../../mocks/screens/<name>.png`.

| File | Screen | What leads |
|---|---|---|
| 01-images.txt | Images | the contact sheet with curation warnings stamped on prints |
| 02-concepts.txt | Concepts | the concept boundary: what NORA7 holds versus what captions describe |
| 03-mapping.txt | Mapping | the open print with its face box, and confirmation |
| 04-captioning.txt | Captioning | the contact sheet developing live as captions arrive |
| 05-publish.txt | Publish | the squared-up stack of 21 prints and the three counts |
| 06-gpu-pods.txt | GPU pods | the price, plus the three stop conditions set before renting |
| 07-training.txt | Training | the training plan as one receipt, time and cost included |
| 08-monitor.txt | Monitor | base and trained models on the same prompts and seeds, as print pairs |

The numbers and file names in the prompts come from the 24-photo demo set, so the comps stay true to what the app can show.

## App icon

Three directions, 1024 × 1024. Render each one or more times, pick one (or a mix), and the chosen file becomes the `.icns`.
- `icon-a-developing-print.txt`: a print half developed.
- `icon-b-trigger-mark.txt`: the highlighted trigger in a print's margin.
- `icon-c-contact-sheet.txt`: four prints, one selected.
